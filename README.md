A one-line entry for the "The Funniest Excuse for Skipping a Meeting" bounty: the funniest single-line excuse for getting out of a pointless work meeting. The classic "double-booked" excuse, except the conflicting appointment is a meeting about this very meeting — and the punchline admits that meta-meeting sounds more useful than the one being skipped. The program validates the line (at most 200 characters, ASCII, single line) and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
